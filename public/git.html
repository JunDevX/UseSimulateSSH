Git через SSH — Руководство (DOCS)

Terminal

1. Генерация SSH ключа

Создание Ed25519 ключа на сервере:

ssh-keygen -t ed25519 -C "your_email@example.com"

2. Просмотр публичного ключа

Скопируйте публичный ключ и добавьте в GitHub -> Settings -> SSH and GPG keys:

cat ~/.ssh/id_ed25519.pub

3. Клонирование репозитория по SSH

Использование SSH URL формата `git@github.com:User/Repo.git`:

git clone git@github.com:JunDevX/UseSimulateSSH.git
